# cppAlgorithms

Личная библиотека реализаций классических **алгоритмов и структур данных на C++**. Собираю сюда всё, что изучаю и разбираю сам — от базовых сортировок до графовых алгоритмов. Репозиторий планируется к интеграции в Android-приложение в виде вычислительного модуля.

## Что внутри

### Algorithms
| Раздел | Реализации |
|---|---|
| **Sorting** | Bubble, Selection, Insertion, Merge, Quick, Heap Sort |
| **Graphs** | BFS, Dijkstra, Bellman–Ford, A* |
| **Trees** | Binary Search Tree, обходы Pre-In-Post (рекурсивные + итеративные) |
| **Stacks** | реализации на массиве и связном списке + применения: проверка скобок, палиндром, инфикс→постфикс, перевод систем счисления, разложение на простые множители 
| **Queues** | на массиве, кольцевая, на связном списке, дек (Deque) |
| **Heaps** | бинарная куча, очередь с приоритетом |
| **LinkedLists** | сложение чисел списками, полиномы |
| **HashTables** | собственная хеш-таблица, работа с `unordered_map` |
| **Greedy** | кодирование Хаффмана |
| **Recursion** | факториал, прямая/косвенная рекурсия, хвостовая рекурсия |

### DataStructures
Университетские лабораторные работы по курсу структур данных (по номерам тем), включая проект на **Qt**. Здесь есть все базовые структуры данных и практика по ним.

## Стек
- **C++** (STL: `vector`, `unordered_map` и др.)
- Часть проектов — под **Qt / QMake**

## Как запустить
Отдельные примеры — самостоятельные `.cpp`-файлы:
```bash
g++ -std=c++17 path/to/file.cpp -o out && ./out
```
Проекты Qt открываются через **Qt Creator** (`.pro`) либо собираются через `qmake && make`.

## Статус
Репозиторий пополняется по мере изучения новых тем. Дальнейший план — обернуть ключевые алгоритмы в переиспользуемый модуль и подключить к Android-приложению.
