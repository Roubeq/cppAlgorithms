# Алгоритм Хаффмана

## 1. Что это?
**Алгоритм Хаффмана** — метод сжатия данных без потерь, который строит оптимальные префиксные коды переменной длины. Частые символы кодируются короткими последовательностями битов, редкие — длинными.

## 2. Для чего нужен?
- Сжатие файлов (ZIP, PNG, MP3, JPEG)
- Экономия трафика и места на диске
- Ускорение передачи данных по сети

## 3. Как реализован в программе?
1. **Подсчёт частоты** символов во входной строке.
2. **Построение дерева Хаффмана**:
   - Каждый символ — лист с весом = частоте.
   - Два узла с минимальным весом объединяются в новый (сумма весов).
   - Повтор до получения одного корня.
3. **Генерация кодов**:
   - При движении от листа к корню: левый потомок → добавляем `"0"` в начало кода, правый → `"1"`.
4. **Кодирование**: замена каждого символа полученным кодом.

## 4. Где используется?
- **ZIP**, **GZIP** — сжатие файлов
- **PNG**, **JPEG** — сжатие изображений
- **MP3** — сжатие аудио
- **HTTP** — сжатие передаваемых данных
- **Файловые системы** (NTFS, ZFS) — сжатие на лету

## 5. Пример работы
Строка: `"abacabad"`

| Символ | Частота | Код |
|--------|---------|-----|
| a | 4 | 0 |
| b | 2 | 10 |
| c | 1 | 110 |
| d | 1 | 111 |

**Закодированная строка:** `01001100100111` (14 бит вместо 64 при обычном кодировании).
